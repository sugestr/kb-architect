# Реестр удалённого

Заводится только если в проекте вообще что-то удаляется. При политике «хранить всё»
(нормальной для приватного личного архива) сюда попадают единичные случаи — и именно
поэтому о них забывают.

Удаление применяется там, где есть основание: субъект попросил, владелец распорядился,
материал попал в архив по ошибке, дубль или полностью воспроизводимое производное.
**Факт** удаления сохраняется — иначе документ вернётся из почты и будет обработан заново.
