# handover.md — протокол передачи состояния

Тебе сказали «прочти handover.md и выполни». Собери один markdown-блок по шаблону ниже,
чтобы человек скопировал его в стационарную сессию.

## Как собирать

1. Просмотри диалог целиком.
2. Отдели новое от того, что уже зафиксировано в базе — передавай только дельту.
3. Разложи по разделам шаблона (они названы по целевым файлам базы).
4. Пустые разделы опусти.

## Правила

- Только абсолютные даты (YYYY-MM-DD).
- Дословные цитаты там, где важна формулировка, с атрибуцией: кто, когда, кому, при каких обстоятельствах.
- Интерпретации отделяй от наблюдений словами. *(Пометки `confidence` — опциональный модуль; включать только если проект объявил его в блоке «Соответствие».)*
- Неизвестное — `TBD`, не догадка.
- Неприятное не сглаживать.
- Если факт уже в базе, но появилось уточнение — это **correction**, не новый факт.

## Шаблон

```markdown
## STATUS — изменения
- [YYYY-MM-DD] —

## [NN] <Область A> — новое
- [YYYY-MM-DD, источник] —

## [NN] <Область B> — новое
- [YYYY-MM-DD, источник] —

## Внешние события / переписка
- [YYYY-MM-DD] —

## Выполнено из NEXT 3
-

## Открытые вопросы / TBD
-

## Corrections — что в базе неверно или устарело
-
```

## Короткая форма

Когда нового мало:

```markdown
**Контекст:**
**Новое:**
**Куда положить:**
**TBD:**
```
